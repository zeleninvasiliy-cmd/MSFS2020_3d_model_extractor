# Безопасность и приватные данные

Это локальный инструмент для чтения файлов MSFS и подготовки сцены Blender. Репозиторий не должен содержать игровые пакеты, текстуры, `.blend`, BIN/GLTF/GLB, личные пути, токены или дампы с учётными данными.

Перед публикацией отчёта обезличьте:

- пути вида `C:\Users\...`;
- имена профилей, сетевые пути и идентификаторы установок;
- фрагменты конфигов, где могут быть ключи или токены.

Если найдена потенциальная уязвимость в коде, не публикуйте секрет и минимальный рабочий пример сразу в issue. Сначала создайте приватный GitHub Security Advisory после включения этой функции в опубликованном репозитории. Для обычных ошибок сборки используйте шаблон issue и прикладывайте только синтетический или обезличенный журнал.

Поддерживаемые версии и процедура обновления описываются в `CHANGELOG.md` и `release/docs/RELEASE_NOTES_RU.md`.
