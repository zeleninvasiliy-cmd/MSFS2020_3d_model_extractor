# MSFS Model Builder 1.2.0

Исходный репозиторий Windows-программы для подготовки статических моделей MSFS 2020 в Blender.
Нужны доступные локальные glTF/BIN; программа не импортирует анимации.

GitHub Actions запускает проверки на Windows. На текущем этапе обычный GUI/CLI использует только стандартную библиотеку Python, а Blender предоставляет bpy/NumPy обработчикам. Для установки из исходников достаточно Python 3.13 x64 и отдельно установленного Blender; запуск: `python msfs_builder_gui.py`.
Готовые EXE/ZIP распространяются через GitHub Releases и не хранятся в истории исходников.

Универсальный статический конвейер MSFS glTF → Blender без профилей конкретных самолётов.

Для обычной установки используйте Setup.exe из опубликованного GitHub Release или соберите его по инструкции `release/BUILDING.md`. После сборки он появится в `release/output/MSFSModelBuilder-1.2.0-Setup.exe`.
Python включён в приложение; Blender устанавливается отдельно. Пути MSFS и Blender
можно выбрать при установке или в меню «Пути и настройки».

Быстрый запуск:

```powershell
python .\scripts\msfs_universal.py inventory "C:\Path\To\Aircraft"
python .\scripts\msfs_universal.py index
python .\scripts\msfs_universal.py models "C:\Path\To\Aircraft"
python .\scripts\msfs_universal.py build .\examples\config.myplane.json --stage geometry
```

Ливреи часто объявляют относительные пути к геометрии базового самолёта. Команда `index` строит индекс установленных пакетов, через который такие пути разрешаются; результат кэшируется в `%LOCALAPPDATA%\MSFSModelBuilder\package_index.json`. В GUI тот же список открывает меню «Индекс пакетов…».

Если доступен не весь объявленный состав, команда `models` печатает кандидатов по ролям — экстерьер и интерьер, все LOD, число вершин и треугольников, источник роли и происхождение файла. В GUI те же данные показывает [мастер выбора моделей](wiki/Model-Selection.md): он открывается сам при выборе такого самолёта и кнопкой «Выбрать модели...» на шаге настройки. Роль, угаданная по имени файла, помечается отдельно и не назначается автоматически.

Пакет не импортирует и не создаёт анимации. Исходные MSFS-файлы используются только для чтения.

Правки собранной модели задаются графически, без редактирования JSON: окно [«Правила редактирования...»](wiki/Rule-Editors.md) на вкладке «Геометрия» (разделение по костям и по координатам, зеркальная копия, привязка к якорю, коллекции, сохранение pivot) и окно «Таблица карт...» на вкладке «Текстуры» (состояние каждой карты, замена файла, выбор из кандидатов, поиск в установленных пакетах). Имена объектов читаются из фактического `.blend` командой `objects`, кости — из JSON glTF командой `bones`, а правила проверяются командой `validate` до запуска Blender.

Оконная оболочка запускается так:

```powershell
python .\msfs_builder_gui.py
```
