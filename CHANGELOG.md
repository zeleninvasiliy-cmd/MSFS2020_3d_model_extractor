# История изменений

## 1.2.0 — подготовлен к публикации

- Индекс установленных MSFS-пакетов и разрешение наследуемых путей между пакетами.
- Мастер выбора exterior/interior и LOD для частичных пакетов.
- Графический редактор правил геометрии: split, mirror, placements, коллекции и pivot.
- Таблица карт текстур с ручной заменой и поиском кандидатов в пакетах.
- Команда `validate` для проверки правил до запуска Blender.
- Команды `index`, `models` и `bones` для диагностики и выбора исходных данных.
- Исправлены выбор checkpoint по номеру, зеркалирование UV/нормалей и наследование позиции placement.
- Общий загрузчик JSON glTF/GLB поддерживает несколько BIN и data URI; geometry adapter материализует sparse accessors и triangle strip/fan.
- Draco, points/lines и дополнительные skin-веса пока остаются диагностируемыми ограничениями.
- Команда `bones` больше не требует секцию `buffers` для metadata-only JSON glTF; второе окно «Кости не загружены» не появляется после такой ошибки.
- Список самолётов в GUI стал иерархическим: ливреи группируются по базовому имени, а список фильтруется по полной, частичной или недоступной сборке.
- Добавлена PolyForm Noncommercial License 1.0.0 для исходного кода проекта.

Артефакты 1.2.0 собраны и проверены локально; публикация в GitHub Release выполняется владельцем после выбора лицензии и финальной визуальной приёмки.

## 1.1.0

- Диагностика пакетов с кодами причин вместо общего статуса «недоступен».
- Глубокая проверка glTF, отсутствующих BIN и неподдерживаемых возможностей.
- Частичная сборка с явным подтверждением доступного состава моделей.
- Исправления управления проектами, checkpoint-файлами, текстурами и упаковкой Windows-релиза.

## 1.0.0

- Первый оконный конвейер MSFS glTF → Blender.
- Геометрия, текстуры, финальная упаковка, проекты и установщик для Windows.
