# Проверка Blender-обработчиков для первого релиза

Дата проверки: 9 ноября 2026. Проверенная среда: Windows, Blender 5.2.3 LTS.

## Исправления

- Отчёты geometry теперь содержат полный `object_catalog` до исключений и фактический `objects` после них. Имена совпадают с Blender, включая суффиксы дублей; скрытые пользователем объекты остаются доступными для следующей сборки.
- Разделение и зеркалирование выполняются до пользовательских исключений: исключённая готовая деталь больше не ломает правило, которое её создаёт.
- Временно скрытые в geometry decal-меши возвращаются при текстурировании.
- `manual` больше не строит неиспользуемые массивы матриц костей. Это уменьшает потребление памяти и устраняет ошибку на pivots с нулевым масштабом, сохраняя прежний способ построения статической модели.
- Источник и роль interior/exterior сохраняются явно. Классификация интерьера больше не теряется после переноса в конечную коллекцию.
- Подсчёт треугольников учитывает совпадающие имена разных mesh и экземпляры mesh. Устранено ложное предупреждение `+992` на штатном Cap10.
- Проверяются границы BIN/accessor, stride, локальный URI буфера и циклы иерархии. Имена BIN с percent-escaping поддерживаются; временный BIN использует независимое имя.
- Обычные normalized integer-атрибуты glTF больше не интерпретируются как MSFS half floats.
- Индексы текстур/изображений проверяются, glTF PBR color/metallic/roughness/emission factors применяются; fiberglass исключён из эвристики прозрачного стекла.
- Исправлена настройка alpha-режима для Blender 4.x/5.x; добавлена проверка усечённых DDS normal maps.
- Полный аудит больше не вычисляет все пары между тысячами несвязанных компонент; для инвентаризации есть быстрый `--objects-only`.
- Открытие входного `.blend` не исполняет встроенные скрипты. Проверяются циклы collection overrides. Skin split с активными `WEIGHTS_1` возвращает понятное ограничение вместо неверного разделения.

## Проверки

`tests/blender_worker_checks.py` запускается Blender в фоновом режиме. Он импортирует синтетический glTF и проверяет каталог исключённых объектов, порядок mirror/exclude, возврат decal-меша при textures, обработку нулевого scale в manual, ошибки accessor/иерархии/texture indices. Проверка завершилась `BLENDER_WORKER_CHECKS_PASSED`.

Штатный Asobo Cap10C собран через CLI в отдельном рабочем каталоге: geometry ~4.6 с, textures ~9.5 с. Оба checkpoint сохранены. Текстурный отчёт показывает 39 используемых и упакованных изображений, 0 packing failures, 37 отсутствующих уникальных карт и недоступные texture.cfg fallbacks. Это результат с предупреждениями (код 2), а не авария сборки. Рендеры и визуальная приёмка геометрии не выполнялись.

## Ограничения

- Проверка на одном установленном Blender не доказывает совместимость со всеми его версиями и всеми сторонними пакетами.
- Уникальная структура MSFS skin, доступность fallback-карт и точность generic-классификации требуют проверки пользователем.
- `manual` намеренно сохраняет статические aircraft-space вершины; если нужен расчёт костей, выбираются `bake`/`hybrid`.
- Один локальный BIN, обычные triangle primitives; sparse accessors и встроенный BIN не поддерживаются. Части с `WEIGHTS_1` требуют пространственного разделения.
- Продвинутые shader extensions MSFS и отдельные KHR texture transforms не воспроизводятся полностью. Финальный `.blend` необходимо проверить в Material Preview.
