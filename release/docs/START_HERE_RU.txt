MSFS MODEL BUILDER 1.3.0 — QUICK START

1. Run MSFSModelBuilder-1.3.0-Setup.exe.
2. Optionally select the MSFS Packages folder and blender.exe in the installer.
3. Start the program from the Start menu and choose Files > New project.
4. Select a simulator package or mod, then choose an aircraft and variant.
5. Build geometry, inspect the .blend in Blender, then run texturing.

Python and Inno Setup are not required on the user’s PC. Blender is installed separately.
Tested with Blender 5.2.3 LTS on Windows x64. The program searches UserCfg.opt;
a Packages folder can also be selected in Paths and settings.

The full manuals are USER_GUIDE_EN.md and USER_GUIDE.md. The package includes
USER_MANUAL_RU.html. The Setup and Portable packages do not include Blender,
aircraft source files, textures, or user projects.

MSFS MODEL BUILDER 1.3.0 — КРАТКОЕ РУКОВОДСТВО

1. Запустите MSFSModelBuilder-1.3.0-Setup.exe.
2. При желании укажите папку Packages MSFS и blender.exe в установщике.
3. Запустите программу из меню Пуск и выберите Файлы > Новый проект.
4. Выберите пакет симулятора или мод, затем самолёт и вариант.
5. Соберите геометрию, проверьте .blend в Blender, затем запустите текстурирование.

Python и Inno Setup на компьютере пользователя не требуются. Blender устанавливается отдельно.
Проверено с Blender 5.2.3 LTS на Windows x64. Путь MSFS ищется по UserCfg.opt;
его также можно указать в меню «Пути и настройки».

Полные руководства находятся в USER_GUIDE.md и USER_GUIDE_EN.md. В установочный
пакет входит USER_MANUAL_RU.html. Blender, исходники самолётов, текстуры и проекты
пользователя в Setup и Portable не входят.
