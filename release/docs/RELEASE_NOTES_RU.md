# MSFS Model Builder 1.2.0

Установочный Windows-релиз статического конвейера MSFS glTF → Blender. Главное изменение — универсальный индекс пакетов, мастер выбора моделей и графические редакторы правил.

## Новое в 1.2.0

- Добавлен индекс установленных пакетов и разрешение наследуемых `base_container`/model-ссылок.
- Добавлен мастер выбора exterior/interior/LOD для неполных пакетов и пакетов без `model.cfg`.
- Добавлены графические редакторы split/mirror/placements и таблица карт текстур.
- Общий слой чтения поддерживает JSON glTF, GLB v2, data URI, несколько BIN, sparse accessors и triangle strip/fan.
- `bones` читает metadata-only JSON glTF/GLB без требования геометрических buffers.
- Список самолётов в GUI группируется по базовому имени ливреи и фильтруется по статусу доступности.
- Вместо единого «недоступен» программа показывает код причины и рекомендуемое действие.
- Частичные пакеты больше не блокируются целиком: доступный состав предлагается пользователю, подтверждается диалогом и сохраняется штатным полем `models`. Имя варианта сборки получает суффикс `_partial`.
- Пакеты без `model.cfg` и модели, разнесённые по разным `model.*`, получают предложенный состав с указанием происхождения каждой модели (`model.cfg`, `xml`, `scan`).
- Ливреи, пакеты общих ресурсов и заглушки под `SimObjects/Airplanes` больше не роняют скан каталога — они получают понятный код причины.
- Поле деталей показывает структурированный читаемый отчёт вместо сырого JSON.
- Ошибка выбора моделей при сборке дополняется блоком «Диагностика пакета».
- CLI: `inventory --deep [--root …]`, `catalog --root … --match …`.

Измеренный эффект на установленной коллекции из 234 самолётов: заблокировано 178 → 8, доступно для сборки 56 → 226.

## Что сохраняется с 1.0.0

- Программа поставляется вместе с Python runtime; отдельный Python не требуется.
- Установка для текущего пользователя через Inno Setup.
- Выбор каталога MSFS и Blender при установке или в программе.
- Автоматический поиск MSFS 2020 через UserCfg.opt.
- Проектный рабочий цикл: самолёт → общие настройки → геометрия → текстуры.
- Сравнение пронумерованных вариантов геометрии.
- Графический выбор состава объектов, фоновые операции, журнал и переход к .blend.

Blender и исходные модели устанавливаются отдельно. В установщик не включены самолёты, текстуры или проекты пользователя. Анимации и встроенный 3D-просмотр не входят в релиз. Проверка на другом компьютере в чистой среде остаётся необходимой частью приёмки перед широким распространением.

Перечень исправлений аудита и проведённые проверки поставляются в RELEASE_AUDIT.md и WORKER_AUDIT.md в папке документации. План дальнейшего расширения совместимости — docs/COMPATIBILITY_ROADMAP.md.
